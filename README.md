# Studi Kasus Aplikasi Login

## Ringkasan
hello world! saya Farrel Irawan peserta dari coding camp 2025 powered by DBS foundation. di repository ini adalah bagian dari tugas praktek saya dalam materi "memulai dasar pemrograman untuk menjadi pengembang software" dan sub materi "studi kasus aplikasi login"

## Fitur
- **Proses Autentikasi**: fitur autentikasi pada email dan password pengguna yang di ketikan.
- **Desain Yang Responsif**: Menyesuaikan tampilan dengan berbagai ukuran layar.
- **Error Handling**: Menampilkan pesan kesalahan untuk input yang tidak valid.

## Teknologi yang Digunakan
- **HTML5**: Untuk membuat struktur dari komponen login form.
- **CSS3**: Untuk memberikan gaya pada setiap komponen komponen.
- **JavaScript**: Untuk fungsionalitas sisi klien dan proses autentikasi.

## Instalasi
1. Kloning repositori:
   ```bash
   git clone https://github.com/username-anda/login-component.git
   ```
2. Masuk ke direktori proyek:
   ```bash
   cd login-component
   ```
3. Buka `index.html` di browser Anda untuk melihat komponen.
